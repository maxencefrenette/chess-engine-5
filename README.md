# Chess Engine 5

Yet another attempt at a chess engine. The goal of this project is to make a lc0-like engine with 100% original code and 100% original training data.

## Methods

* MCTS with neural nets ([AlphaZero](https://arxiv.org/abs/1712.01815), [Leela Chess Zero](https://lczero.org/))
* SPRT testing ([Fishtest](https://github.com/official-stockfish/fishtest))
