# 5,000-game self-play dataset

Test whether one epoch on 5,000 games generated by the current baseline improves playing strength over the existing checkpoint.

Source revision `ea23b95` plus local datagen changes. Commands, config snapshots, and logs are in `/data/chess/chess-engine-5/models/datagen-5000-experiment.SUaj4m`.

## Data generation

Generated 5,000 games and 839,120 positions in 5 shards in 3.37 hours. Each game started from the standard position with 800 visits per move and temperature 1.0.
Used 250 games per batch and 1000 games per shard. In the opening benchmark, batch 250 ran at about 78,000 leaves per second versus 17,500 for batch 16.
Generator checkpoint `/data/chess/chess-engine-5/models/smolgen-v1-1000games-policy-piece-wdl-seed42`. Dataset `/data/chess/chess-engine-5/training-data/v2/1794199969642733611-305557`.

## Training

Trained for one epoch on the new dataset.
Timed runtime was 145.35 seconds for 5,904 optimizer steps. Held-out policy loss was 2.4139 and WDL loss was 0.8692.
Candidate checkpoint `/data/chess/chess-engine-5/models/datagen-5000-experiment.SUaj4m/checkpoint`.
